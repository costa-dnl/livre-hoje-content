# Livre Hoje — Conteúdo público

Este repositório disponibiliza o catálogo público de mensagens de inspiração usado pelo aplicativo **Livre Hoje** e versões de teste do APK Android.

## Versão oficial

Baixe a versão oficial do [Livre Hoje no Google Play](https://play.google.com/store/apps/details?id=com.stunks.livrehoje).

## Baixar versão de teste

[Baixar Livre Hoje para Android](https://github.com/costa-dnl/livre-hoje-content/releases/latest/download/Livre-Hoje.apk)

> A versão de teste pode conter novidades ainda em validação.

## Catálogo de mensagens

O arquivo [messages.json](messages.json) contém as mensagens de inspiração consultadas pelo aplicativo.
